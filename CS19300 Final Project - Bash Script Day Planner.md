This script is supposed to run every morning would be connected to databases like Obsidian or Notion where the script pulls the most important or high priority assignments to be done in according to due date, how soon the next exam is, and a personal priority setting from the user. The script will greet the user and then output the most important assignments to get done that day. It can be organized in one big checklist or it can be organized by class.
